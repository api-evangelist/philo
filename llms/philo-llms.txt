# Philo

> Philo is a US live-television streaming service founded at Harvard in 2010 as Tivli,
> renamed in 2013 after television inventor Philo T. Farnsworth, and launched publicly
> in 2017. It offers 70+ live channels, 75,000+ on-demand titles, 120+ free ad-supported
> channels and unlimited one-year DVR from $25/month. Philo publishes **no public API,
> SDK, webhook surface or developer program**. This file is generated by API Evangelist
> from independently probed public sources; it is not published by Philo.

## API surface

Philo has no developer-facing API. The following was observed on 2026-08-05:

- [Product GraphQL endpoint](https://www.philo.com/graphql): live (Apollo Server, returns
  JSON), but **introspection is disabled** (`GRAPHQL_VALIDATION_FAILED`) and it is
  undocumented. It is the private backend for Philo's own web/mobile/CTV clients, not a
  published API.
- No OpenAPI, Swagger, AsyncAPI, JSON Schema, Postman collection, MCP server or A2A agent
  card was found on any Philo host.
